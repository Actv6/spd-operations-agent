## M1 可演示范围

- 注册→本人隔离项目→数据库库存与知识→Agent 异步核查→引用回查→历史记录→退出。
- 实际只读库存工具、词法检索和 DeepSeek 回答；库存、缺日、无依据三条真实调用已核验，不代表广泛准确率。mock 仅保留为自动测试能力与历史标记，不是当前业务入口。
- 库存搜索/科室与状态筛选/排序/分页/详情；行内发起核查；结果、库存事实、引用原文与历史记录。
- 每个医院 A 项目当前有 46 份有效资料、124 个入库片段；新增 42 份包括 12 份操作指引、24 份物资卡和 6 个案例，旧版本保留。
- 失败、取消、事件游标、幂等、租约重试与检查点恢复；数量为 Decimal 字符串。

## 保留的旧原型范围（/prototype）

- 三列任务看板、任务详情、负责人分派与处理记录。
- 待核查 → 待确认 → 处理中 → 已完成的本机演示流程。
- 库存与批次依据、模拟制度、医院切换、关键词筛选与历史版本显示。
- 任务变化仅保存于浏览器 localStorage；不具备服务端权限隔离和多用户协作能力。

执行顺序：前后端注册登录 → 基础后台 → 独立 Agent 与 RAG → 前端联通。主模型按用户要求使用 DeepSeek；key 仅存后端配置。正式公司试点、腾讯云部署和新增业务模块不属于本次 M1 完成声明。
