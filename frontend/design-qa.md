# 前端视觉与交互验收 · 2026-09-27

**结果：passed（前端原型范围）**。不代表公司试点、真实 Agent、RAG、账号安全或线上部署已验收。

## 目标与方法

- 唯一视觉目标：`../design/prototype-3.png`，1484 × 1060。
- 对比页面：医院 A，默认任务看板，第一项待核查任务，未打开弹窗。
- 最终浏览器截图：1484 × 1060，DPR 1，无截图缩放；原图与截图同框比对。
- 全页同框证据：`qa/comparison-full.png`；右侧详情局部同框：`qa/comparison-detail.png`。
- 原型图中的实际品牌、价差与条码占位被替换为明确的 SIM 演示物资和本期缺货、效期、数据核查场景。

## 发现与修正

| 级别 | 发现 | 修正与结果 |
|---|---|---|
| P2 | 首版标题、任务名称与资料链接较原图偏小，层级不明显 | 提升桌面标题、卡片文字、详情步骤与链接字号；全图和详情局部复查通过 |
| P2 | 常驻筛选栏将任务列下推，削弱原图紧凑层级 | 改为标题右侧“筛选”开关，默认收起；筛选能力保留 |
| P2 | 重置时若选中任务未改变阶段，表单草稿可能残留 | 重置显式清空负责人、截止时间草稿、结果和搜索条件 |
| P3 | 原图生成字体与系统中文字体字形有差异；原生日期选择控件外观不同 | 使用可用系统字体和语义化原生控件；不影响操作与中文可读性 |
| P3 | 实际八项任务比原图六张卡片更多；详情纵向间距略大 | 数量与合成场景一致；低高度详情独立滚动，按钮可达 |

未发现未解决的 P0/P1/P2 视觉或已测流程问题。P3 为原型阶段明确保留的差异，不称像素级复刻。

## 视觉覆盖

- 布局：深蓝固定侧栏、顶部医院切换、白底工作区、三列任务、右侧详情，顺序及主要比例符合目标。
- 字体与密度：标题、卡片、标签、表单保持层级；长任务名可换行。
- 颜色与表面：蓝色主操作与选中态，黄色待确认、绿色处理中，浅色卡片和边框；沿用同一套语义颜色。
- 图像与图标：业务界面无需照片；使用 Tabler 图标库，不以手工插画替代真实素材。圆形文字为演示岗位标记，不是真人头像。
- 响应式：1484 × 1060 桌面、768 × 1024 平板和 390 × 844 手机已观察。平板将任务列表与详情并列；手机详情可收起，列表为单列。后两者 DOM 测得页面无横向溢出。
- 可访问性基础：原生按钮、输入与选择框，主要控件有中文标签；焦点轮廓可见；原生 dialog 支持 Escape；有 reduced-motion 样式。未进行完整屏幕阅读器、对比度扫描或 200% 缩放认证。
- 状态：任务选中、待确认、处理、完成、必填错误、医院空态、搜索、历史版本和本地保存均有对应交互。

## 功能与构建证据

`qa/interaction-results.json` 记录 18 项通过的浏览器断言，覆盖：缺少负责人时阻止提交、创建待办、库存证据、有效制度、完成结果必填、完整生命周期、已完成筛选、刷新保留、医院空态、版本过滤、医院资料过滤、缺失数据展示、重置、Escape、手机收起与窄屏溢出检查。

浏览器采集的 error/warn 日志为空。TypeScript `tsc --noEmit` 成功；Vite 生产构建成功，JS 约 233 KB（gzip 约 72 KB）。这些是当前前端的验证结果，不是服务端测试。

本机 pnpm 启动脚本曾触发自动依赖重装并因无 TTY 中止；已用本地 Vite 与构建准备脚本完成构建，随后通过 `pnpm_config_verify_deps_before_run=false` 完整执行了 pnpm build。此覆盖仅用于本机现有依赖，未写入项目；运行说明采用标准 Node 环境的 `npm run` 执行脚本（当前捆绑运行时没有 npm）。依赖锁文件统一为 `pnpm-lock.yaml`，明确允许官方 esbuild 的安装脚本。没有对服务器或第三方账号进行更改。
