## Technical design baseline

Design selections: LangGraph; DeepSeek official API with configurable deepseek-flash; FastAPI modular monolith with one background worker; React/TypeScript; PostgreSQL/SQLAlchemy/Alembic. M1 RAG first uses real lexical retrieval with scoped, versioned citations. Prepare an embedding interface and pgvector migration; text-embedding-v4 at 1024 dimensions is optional later and needs its own provider configuration. Do not create fake semantic vectors. Read docs/blueprint/11-技术与模型选型.md and 13-M1开发交接.md. These are design choices, not verified deployments; verify account model availability when a key is provided.

Keep calculations, permissions, approvals, transactions and idempotency deterministic. One operational Agent uses scoped tools and RAG. Model failures must remain distinguishable from rules-only fallback. Real company data, published systems, browser mocks, automated checks and real-model evaluations are separate evidence categories.
