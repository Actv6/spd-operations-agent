# M1 接口与测试基线

版本 `m1.1`，2026-09-27，实际作者/复核者：当前 Codex 助手（同一实现者，无独立 QA 签字）。实现前冻结本文件；OpenAPI 由 Pydantic 生成，前端类型由 OpenAPI 生成。

## CR-M1-001：收窄本轮协议

沿用 06/12 的 `/api/v1`、错误 envelope、run/event/analysis/evidence 结构。M1 仅开放 `mode=analyze`、`session_id=null`、`parent_run_id=null`、`analysis_id=null`、14 天窗口；其他模式返回 422。不实现审批或业务写入。增加 GET `/csrf`、`/health`、项目 `/dashboard`、`/knowledge/search?q=`、`/runs` 历史列表。模型选择完全来自后端配置。注册创建本人组织和一个医院 A 的隔离 synthetic 项目。前端仅展示服务端项目。

- POST `/registrations`：`{email,password,display_name}`，201 返回 user/project 并建立会话；POST `/sessions`：`{email,password}`，200 同形状；DELETE `/sessions/current`：204。
- 所有写操作需要 GET `/csrf` 所得 token 的 `X-CSRF-Token`，且匹配签名 Cookie；Origin 必须匹配允许列表。认证 Cookie 为 HttpOnly、SameSite=Lax；生产 Secure 可配置。
- GET `/me`：`{user:{id,email,display_name},projects:[{id,name,synthetic}],capabilities:[...]}`。
- 创建 run 请求严格沿用 12 第 2 节字段，Idempotency-Key 必填，202 返回 run_id/session_id/status/revision/snapshot_set_id/as_of/trace_id；同 key 不同 body 返回 409。
- run 状态只使用 queued/running/succeeded/failed/cancelled；预留 degraded 与 generation_mode=rules_only，但 M1 不自动降级。缺 key 的 deepseek 运行 failed，绝不切换 mock。
- events 使用持久化递增字符串 cursor，after 默认 0、limit 1–200；结果存储 analyses；引用 GET `/evidence/{id}`。每次访问校验项目成员。
- CR-M1-002：run 摘要增加只读 `question`，使历史卡片与原始问题对应；兼容性新增，不改变请求或持久表结构。前端同步从 OpenAPI 生成。
- CR-M1-003：dashboard 增加 `provider_configured` 布尔值，模式选择与配置就绪分开；该值不表示真实模型质量已验收。
- analysis：generation_mode 为 mock/model/rules_only，retrieval_mode 固定 lexical；answer、citations、inventory、warnings、provider_metadata、版本与快照字段。数量是 decimal string；mock usage/cost 为 null。模型引用必须来自本次召回证据。
- 工具仅 get_inventory 与 search_knowledge；JSON 参数 Pydantic extra=forbid；项目/用户由服务器绑定；工具次数与时限有界。知识片段作为不可信资料处理。

## 先行测试设计

| 分组 | 必测行为 |
|---|---|
| 身份 | 注册、重复账号、错误密码、密码哈希、匿名/过期/退出会话、CSRF/Origin 拒绝、限流 |
| 权限 | 两用户项目隔离；run/analysis/evidence/知识/库存跨项目统一 404；撤权后 worker 拒绝 |
| 数据 | 从数据库读取；120/20=6；缺日未知；冻结/预留/过期剔除；数据来源版本固定 |
| 队列 | 并发领取只一份；过期租约重试；最多 2 次；fencing 拒绝旧 worker 写入；幂等冲突；取消 |
| Agent | 独立 API 建 run→worker→events→analysis；未知工具、越界参数、调用预算、坏 JSON、超时、429、缺 key 明确失败 |
| RAG | Markdown 实际导入与 hash；章节/offset 可回查；有效版本、未来/过期过滤；医院 B 拒绝；空命中；重复导入；虚假引用拒绝 |
| FE | 注册→后台→刷新→问答→引用→历史→退出→受保护路由拒绝；错误密码；离线提示；桌面/窄屏 |
| 运维 | 迁移空库、重启后结果仍在、锁依赖、运行说明；PostgreSQL 与 pgvector 无环境则单列未验证 |

## 环境决策

2026-09-27 PATH 与常见安装目录未发现 postgres/pg_ctl/docker，5432 无服务，Docker socket 与 Postgres.app 不存在。按 13 的授权使用 SQLite 本地开发，保留 PostgreSQL SQLAlchemy 配置和完整表迁移；pgvector 单独 opt-in 迁移。前端已有 4173 原型服务，M1 使用独立 4180 端口。
