# 导入与文件上传优化基线

2026-09-28，用户授权导入流程测试、布局优化、大文件处理及上传组件封装。作者与实现自检：Codex；无独立QA。

沿用M3.2业务范围与紧凑台账。库存/批次/消耗完整CSV、手动预览与发布、主数据Hash和快照revision、历史不可变性保持现有契约。

先行测试设计：模板下载后同步调整库存及对应批次的在库量；校验前后当前快照不变，预览应显示变更。错误单位/编码、文件扩展名、UTF-8、空文件、大小、10000行边界应给明确错误。上传读取期间不得提交；取消/替换/移除不能被旧读取结果覆盖。分别验证桌面与390px布局，保留失败证据。

契约调整（实现前记录）：ImportFiles字段字符上限及服务端UTF-8字节上限由1MiB提高到10MiB；保留10000条数据行上限。接口路径和JSON形状不变。前端以256KiB切片增量解码，不一次读取整个ArrayBuffer；显示本地读取进度，服务器校验显示真实等待状态。此轮不实现分片网络传输、断点续传或后台导入任务。

测试数据来自项目生成场景，非真实公司数据。默认测试只生成预览；发布与回退的自动验证使用隔离数据库。
