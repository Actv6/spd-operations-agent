# 上传空状态布局修复

2026-09-28 用户截图指出拖拽上传框溢出卡片并遮盖填写规则。此前验收检查了页面横向溢出和已选择状态，遗漏了空上传框的纵向边界；此次补齐。

根因：Ant Design Dragger的drag区域和按钮默认height:100%，在CSS Grid拉伸卡片内按整个卡片高度计算，再叠加标题、说明和下载按钮，导致溢出。

修复只涉及共享上传组件CSS：wrapper按块布局，drag与btn高度auto，btn最小高度125px并以flex居中，drag-container改为block。保留按钮、读取、校验与业务行为。
