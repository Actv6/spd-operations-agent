范围：只修改前端展示，未重新生成AI回答、未写回原始回答或引用。

1. 缩小问题标题、收紧顶部留白；快照时间只展示到分钟。
2. 大面积蓝色扫描Alert改为浅灰紧凑统计；不可估算为0时不重复罗列零值原因。
