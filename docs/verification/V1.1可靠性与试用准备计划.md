# V1.1 可靠性与试用准备计划

日期：2026-10-01。用户要求先制定计划再执行。作者、实施、自检：当前 Codex；尚无独立 QA 或业务评审。

## 目标与范围

在已有九菜单与 M3.2 业务边界内，完成回答可靠性、可重复离线评测、人工反馈、基础知识维护及业务评审材料。当前用户指令授权这些本地可逆实现，不自动授权部署、真实医院数据接入、采购/库存交易回写、对外发送或新的付费模型轮次。历史答案、引用、快照保持原样。不得把单元测试、模拟 provider 或离线评测写成真实模型准确率。

## 执行顺序和出口

| 阶段 | 实施项 | 验收出口 |
|---|---|---|
| A 回答可靠性 | 服务端保存并展示风险分级与清单；扩展数字变体校验；无依据绝对化表述检查；提示版本升级 | 总数正确但分级错误、中文数字、共/共有、Markdown、反向计数、一次纠正与持续失败均有回归；旧答案不重写 |
| B 可重复评测 | 固定离线挑战集、答案校验与词法召回评测脚本、机器可读报告、人工语义评审表 | 默认不调用模型，不读取日常数据库；显式列出范围与不支持的语义证明；区分开发回归集与尚未盲测的人工用例 |
| C 反馈闭环 | 结果页提交有帮助/需修正及原因；不可变反馈记录关联运行/模型/提示/知识版本；本人反馈回读 | 登录/项目/运行权限、CSRF、重复请求幂等、反馈不改答案与任务；前端提交失败可重试 |
| D 知识维护 | 既有知识页新增文本资料预览、人工发布、停用；版本冲突阻断、变更留痕；检索匹配提示 | 仅项目所有者管理；Markdown/文本、有长度限制；预览不入检索；过期预览不得发布；历史正文/引用保留；停用资料不再召回 |
| E 验证与交接 | 临时数据库迁移/回归，前端类型/构建，浏览器可用时走查；准备业务评审与真实复测方案 | 记录实际通过数、缺陷及未验证项；形成完成报告和复现命令 |

A→B→C→D→E 顺序执行，不创建并行代理。测试设计与接口契约先于实现。使用现有 React/Ant Design 紧凑台账和 Python 模块化单体，不增菜单和基础设施。

## 共享契约（实施前记录）

- `AnalysisView` 增加可选 `risk_priority_summary: {high, medium}` 与 `risk_findings: RiskFinding[]`，来自本轮工具事实；旧记录为 null，不回填。前端分级和清单来自这些字段。
- `GET/POST /analyses/{id}/feedback`：本人反馈列表/追加记录。请求包括 `rating: helpful|needs_correction`、`comment`（最多1000字）；需修正必须写原因。POST 需 `Idempotency-Key`，同键同内容回原结果，异内容409。返回反馈ID、时间、评分与说明，服务端记录运行、快照与版本上下文。只允许运行本人提交/读取，另校验现时项目权限。
- `GET /projects/{id}/knowledge/manage`：所有版本、管理权限、版本令牌、变更历史。
- `POST /projects/{id}/knowledge/preview`：所有者预览标题、版本、正文、来源说明，返回源hash、片段、当前目录令牌，不写库。
- `POST /projects/{id}/knowledge/publish`：携带同一正文与令牌、`Idempotency-Key`，事务内重校验后发布新版本，禁止覆盖已有内容及同名有效版本冲突。用户需先停用被替代版本；没有静默替换。
- `POST /knowledge/documents/{id}/retire`：令牌、原因、`Idempotency-Key`，仅停用并留痕，不删除正文、片段或证据。项目行锁串行化目录修改；目录hash用于预览失效检测。
- 知识管理界面明确人工发布、生效/停用状态；当前项目仍为授权生成场景，上传来源是用户声明，不自动背书为真实公司资料。
- 新增反馈、知识变更表及 Alembic 迁移。生成 OpenAPI 与 TypeScript 类型，不手改生成类型。日常数据库如需迁移，先一致性备份并核验历史数量；测试只操作临时库。

## 测试设计

1. 错误数字至少覆盖阿拉伯数字、中文数字、全角、空格、Markdown、插入“共/共有”、倒装；正确数字/无计数说明不误拒绝。校验不能证明任意自然语言完整正确。
2. 无适用依据区分“本次未检索到”与“本库不存在”；一次纠正后保留全部usage，持续错误不可保存成功分析。
3. 回归与挑战集包含来源定位、同义查询、无命中、版本过滤、权限隔离；真正盲测与业务专家判断不得由作者自检代替。
4. 反馈跨用户/项目拒绝，幂等冲突拒绝，历史Analysis.body逐值保持一致。
5. 知识预览无副作用；停用后不召回；源文与hash不变；并发/旧令牌409；未授权成员403；空白/超长资料422；SQL迁移在临时SQLite实跑，PostgreSQL仅离线SQL不能标记实连通过。
6. 前端新表单含空、忙、失败、重试与成功状态；项目/分析切换取消旧请求，避免旧反馈或预览回填。
