# V1 全站验收与体验收尾基线

2026-09-28 用户批准；作者/自检Codex，无独立QA。功能范围冻结于M3.2，沿用紧凑台账，不扩展菜单、采购或Excel，不部署、不调用付费模型、不修改历史AI回答。

先行页面截图见 v1-acceptance-ui。实际观察：
1. 工作台/9菜单：720px高时侧栏末尾知识库被下推，需要滚动；收紧导航间距和辅助区。
2. 核查结果：单物资Markdown可读；全项目24张事实卡默认展开，引用与后续操作远离结论；多物资事实改折叠台账。旧回答【标题】没有呈现层级，仅转换排版，不改文本结论。
3. 文档引用正常。批次工具引用实测为空白；代码同样遗漏consumption/risks类型。补齐四种工具证据，未知历史类型显示原始摘录以防无声空白；原快照与Hash不变。规则结果与AI结果标签保持区别。
4. 异常→批次：过期隔离状态显示英文quarantined_expired，列宽不足使日期和表头竖排。共享批次表格、明确横向滚动、中文状态。消耗页加载/失败应显示同一个状态与重试入口。
5. 本人任务：当前任务与原依据可读。代码发现慢响应在关闭后可能重新打开抽屉，补齐请求序号与关闭保护；冲突保留说明、刷新状态后再操作。
6. 库存、物资、科室、导入、知识库、版本既有入口可访问；继续验证搜索/空结果/表单/窄屏。知识库全局刷新当前未刷新目录，补齐刷新联动与详情错误重试。

验收：本轮截图before/after、桌面与390px；真实本地只读查看现有模型结果/引用，不将其当作新模型评测。临时数据库以明确mock测试完整导入→扫描→Agent→引用→草稿→任务→回退流程及权限，回归后端/前端/类型/构建。备份还原测试仅在临时文件执行。线上PostgreSQL、生产并发、云部署、独立业务语义验收保留未验收状态。
