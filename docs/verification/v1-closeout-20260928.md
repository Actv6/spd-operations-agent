## 修正

- 全项目风险扫描现在从确定性扫描结果计算高/中关注数量。明确写出关注级别数量的模型回答若与扫描不符，会触发一次既有格式纠正；再次不符则运行失败，不保存为成功分析。没有新增 API 字段。
- 工作台关注列表按高优先级优先排序；同级时效期关注优先，其余维持原扫描顺序。
- 既定收尾基线中的其余修正经代码复核已存在：风险刷新固定当前快照并拒绝混合版本；库存、批次、消耗、风险工具证据可分别展示；未知历史证据保留原始摘录；过期隔离状态中文展示；任务与资料详情请求有关闭/重选保护；知识刷新会重新读取目录；多物资事实折叠展示，旧 Markdown 标题只调整层级不改事实文本。
