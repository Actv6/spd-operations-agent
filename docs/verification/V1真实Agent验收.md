> 中关注 6 条：生化清洗液……样本稀释液……样本杯……一次性吸头……尿液分析试纸……

正确清单：

- 高关注3条：检验质控材料效期、反应杯缺日、采样管旧快照。
- 中关注5条：4条低覆盖、1条临期。
- 合计8条，与结构化总数一致；错误发生在模型正文的分类数量。

根因定位：`risk_summary` 校验扫描量、跳过量、原因和总异常数；`validate_business_answer` 还检查业务编码和内部字段外露，但没有核对正文的关注级别数量。将此次错误回答重新送入当前校验函数，它仍被接受。见 [只读复现结果](v1-live-20260928/guard-gap-reproduction.json)。这说明结构化校验通过不足以证明正文数字正确。

建议下一个修复范围：由服务端产生关注级别统计与清单，避免模型再次数数；核查正文出现的分级数量与确定性结果是否一致，不一致时只允许一次纠正，持续错误应明确失败。测试同时覆盖总数正确但分级错误、数值省略、分级同义表达，不能只把本次数字写进提示词。历史回答保持原样。
