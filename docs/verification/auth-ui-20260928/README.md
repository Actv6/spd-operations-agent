# 登录与注册 UI 优化 · 2026-09-28

执行者：Codex。本次为实现者自检，没有独立 QA 或用户视觉验收。

## 范围

- 使用 Product Design 的 index、user-context、get-context 指引，结合用户截图及现有蓝白工作台设计。
- 修改 `frontend/src/m1/WorkbenchApp.tsx` 的 Auth 和限定于 `.auth-page` 的样式：统一双栏面板、蓝色介绍区域、表单层级、44px 输入框、手机单栏。
- 保留 `/sessions`、`/registrations` 请求与会话成功回调；补充注册密码要求、输入提示、提交期间禁用与首个错误聚焦。后端、Agent 和 RAG 未改动。

## 验证

- TypeScript 类型检查通过。
- Vite 生产构建与 Sites 本地打包脚本通过；沿用已有大包警告（主包约 1.39 MB，gzip 444.58 kB）。没有发布或部署。
- 既有共享 UI 测试 5/5、打包路由测试 4/4 通过。这些测试不是新增的认证端到端测试。
- 浏览器检查：1280×720 桌面、390×844 手机；320×740 注册页横向宽度实测 320px，无横向溢出。
- 登录/注册切换正常，表单与错误状态重新初始化。
- 注册空提交聚焦姓名，显示全部必填错误；无效邮箱和短密码显示对应错误。
- 密码显隐切换成功，输入类型从 password 变为 text。
- 向本地服务提交不存在账号的登录请求，页面显示“邮箱或密码不正确”，结束加载并恢复表单操作。
- 未新建账号，未重复测试成功注册/登录，未测试真实手机键盘或密码管理器自动填充。
