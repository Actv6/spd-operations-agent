# M2.1 回答质量收尾 · 2026-09-28

本轮修正已落地并重启本地服务。完成六场景回归、两例定向复核和一次独立最终输出纠正；这些是不同版本、不同验证层级，不能合并称作最终版本六例全量端到端通过。执行与审阅均为当前 Codex，没有独立 QA 或业务专家审核。

## 修改

- 删除最终输出指令中无条件要求补充效期风险的句子，只说明与当前问题相关的缺口。
- 根据本轮实际扫描状态补充完整/部分范围，明确风险扫描已包含效期筛查，逐批明细是另一层证据。
- 追问遵守用户限定范围，减少重复检索；草稿正文简述事实，步骤放在待办区。
- 区分记录事实、制度要求和建议，不自行规定零记录出具人或形式。
- 区分个别日期零记录与整个14日窗口日均为零：有据补齐后，完整有效的新快照可由工具重新计算，不推造计算结果。
- 将 task_draft、evidence_ids、risk_summary 等内部字段纳入已有业务用语校验；继续使用一次纠正机会，持续错误明确失败，不替换模板。
- 调用元信息保存内部提示版本 `m21-quality-3`。API、数据库结构、库存计算、权限及任务确认流程不变。未重写旧回答。

涉及代码：backend/app/agent.py、providers.py、answer_quality.py；补充受控回归与评测脚本。阶段性提示版本2的原始结果保留，不冒充最终版本结果。
