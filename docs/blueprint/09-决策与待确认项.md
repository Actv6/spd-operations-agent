## 4. 来源与证据边界

技术事实优先链接到官方文档：LangGraph 的状态/人工中断，pgvector 的检索，百炼/DeepSeek/火山的模型能力。11 保留本次查询到的具体型号和链接；产品阈值、角色和部署策略是本项目设计，不是厂商推荐的完整方案。

此前 `docs/调研与实施建议.md` 是早期探索记录，当前范围和流程以本目录为准。公开岗位/采购资料只支持场景相关性，不能证明公司真实痛点、业务收益或已同意接入。

若官网不同语言/发布日期的页面有矛盾，以具体接口/模型现行文档和账号实测继续核实；不把旧新闻中的迁移计划当作已经发生的运行事实。本次没有使用外部评测榜单推导 SPD 准确率。
