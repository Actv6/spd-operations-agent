## 针对 SPD 的设计要求

- 工作台先显示需要处理的异常与依据，长期操作以表格、列表和详情为主。
- 严重性同时用文字和图标，颜色只辅助，不只依赖红绿。
- 数字右对齐、等宽数字；数量必须带计量单位；长产品名、规格和批号有完整查看路径。
- 持续显示数据业务时间；按用户后续要求，当前业务界面不重复放演示标签，生成来源保留在数据 provenance 与审计字段；旧快照与实时企业采集不可混称。
- 给缺失数据、无检索结果、模型超时、任务重复提交和权限不足设计明确状态。
- 主行动明确：核查、生成草稿、确认待办；模型建议和已执行任务在文案上区分。
- 适配常见办公屏幕，核心桌面设计目标 1440×1024，同时检验 1366×768、缩放和键盘使用。
- 不用装饰性图表代替信息；没有足够数据时不编造趋势或业务成果。
