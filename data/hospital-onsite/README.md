## 复现与发布

项目根执行 `backend/.venv/bin/python scripts/generate_hospital_onsite.py` 只生成文件。先备份数据库；在 backend 目录执行 `.venv/bin/python -m app.cli publish-onsite --project-id <项目ID>`。不指定项目时应用于现有、标为 synthetic 的受支持医院项目。新增账号未自动应用此扩展，需显式运行发布命令。

发布在项目事务锁内向当前快照追加，不替换现有行；同步追加目录、独立知识版本和版本切换记录。整个命令提交一个事务；冲突抛错并回滚。发布不修改旧事实或旧引用，不执行采购、库存交易回写、任务确认或模型调用。项目已发布过该版本时重复调用不做操作，手动回退后也不强制重新激活；需要恢复扩展时到数据版本页选择已发布快照。

导入资料是词法检索入库，不是模型训练。后端验证报告在 docs/verification/医院驻场数据补充-20260929.json；49项相关测试涵盖数据发布、CSV导入及版本管理，未运行新一轮真实模型或浏览器验收。
